# 🚀 How to Set Up Your New Aesthetic GitHub Profile

Your personalized, high-aesthetic GitHub profile `README.md` has been created in this folder! Follow these simple steps to activate it on your GitHub profile (`https://github.com/basasindhu04`).

---

## 📋 Step-by-Step Instructions

### Step 1: Create Your Profile Repository on GitHub
1. Go to [GitHub New Repository](https://github.com/new).
2. Set the **Repository name** to exactly: `basasindhu04` (matching your username).
3. Ensure the repository visibility is set to **Public**.
4. Check **Add a README file** (or leave it unchecked if you're pushing from local git).
5. Click **Create repository**.

---

### Step 2: Push These Files to GitHub

Run the following commands in your terminal inside this folder (`c:\Users\basas\OneDrive\Documents 1\Desktop\github-profile`):

```bash
# Initialize git repository
git init

# Rename branch to main
git branch -M main

# Add all files (README.md and .github workflow)
git add .

# Commit changes
git commit -m "feat: add aesthetic and dynamic profile README"

# Add remote origin (replace if already created)
git remote add origin https://github.com/basasindhu04/basasindhu04.git

# Push to GitHub
git push -u origin main --force
```

---

### Step 3: Enable the Dynamic Snake Contribution Animation 🐍 (Optional but Recommended)
1. Go to your repository on GitHub: `https://github.com/basasindhu04/basasindhu04`.
2. Click on the **Actions** tab.
3. Select **generate animation** from the left sidebar.
4. Click **Run workflow** -> **Run workflow**.
5. Once it completes, your snake contribution animation will automatically update on your profile every 24 hours!
